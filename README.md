# Fotomatic

A debugging project from Codecademy's Full-Stack Engineer path. Codecademy gives you a landing page for Fotomatic, a made-up instant camera, but the HTML and CSS are full of bugs. The job is to compare it to how it's supposed to look and track down what's broken.

Live site: https://ktforge.github.io/fotomatic_broken/

It's good practice for reading someone else's code, which is most of the job in real life, and for using the browser dev tools to figure out why something isn't showing up where it should.

## Running it

Clone the repo and open `index.html` in your browser.
